# Page reference

Every page in Acme Tasks, with its address and what it's for. To learn how to
use a page, see its guide in `docs/guides/`.

| Page | Address | What it's for |
| --- | --- | --- |
| Quick add | http://localhost:8092/type-echo.html | Type a task and check it before you add it. |
| Search | http://localhost:8092/find-regex.html | Find tasks that match a pattern. |
| Tabs | http://localhost:8092/multi-tab.html | Open a task in a new tab. |
| Board | http://localhost:8092/drag-drop-test.html | Move tasks between columns. |

## Keyboard shortcuts

| Keys | What it does |
| --- | --- |
| `Ctrl+K` | Open search. |
| `Ctrl+Enter` | Add the task you typed. |
| `Esc` | Close the open panel. |
