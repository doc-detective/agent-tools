# Demo app resources

Bookmark these pages. You'll use them throughout the demo app tutorials.

## Web app pages

- [Home page](http://localhost:8092/): the starting point for every task, with
  sample controls and data.
- [Layout editor](http://localhost:8092/drag-drop-test.html): build dashboards by
  dragging widgets onto a canvas.
- [Live preview](http://localhost:8092/type-echo.html): check text as you type it.

## API

- [API status endpoint](http://localhost:8093/status/200): returns `200 OK` when
  the API is up. Use it in uptime monitors.

## Getting help

If a link doesn't work, make sure the demo app is running on your machine. The web
app uses port `8092` and the API uses port `8093`.
