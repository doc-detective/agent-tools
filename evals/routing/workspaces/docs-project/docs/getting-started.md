# Get started with Acme Widgets

1. Go to [the Acme Widgets app](http://localhost:8092).
2. Click **Sign in**.
3. In **Email**, enter your work email address.
4. Click **Continue**. You should see the **Dashboard** heading.

## Create your first widget

1. On the dashboard, click **New widget**.
2. Enter a name for the widget, then click **Save**.
3. The widget appears under **Your widgets**.
