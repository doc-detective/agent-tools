# Use the live preview

The live preview shows exactly what you type, as you type it. Use it to check the
spelling of a name or code before you save it anywhere else.

## Preview your text

1. Go to `http://localhost:8092/type-echo.html`.

2. Click the **Type here** field.

3. Enter `Hello, Doc Detective`.

   The preview line below the field updates with every keystroke. When you finish
   typing, it reads **Hello, Doc Detective**.

If the preview stays empty, make sure the cursor is in the **Type here** field and
not elsewhere on the page.
