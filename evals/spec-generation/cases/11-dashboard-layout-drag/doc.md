# Arrange your dashboard layout

The layout editor lets you build a dashboard by dragging widgets from the
**Widgets** palette onto the canvas. The canvas has two drop zones, one for each
column of your dashboard.

## Add widgets

1. Go to `http://localhost:8092/drag-drop-test.html`.

   The status bar at the top of the editor reads **Page loaded - drag and drop
   ready**.

2. Drag the **Table** widget from the palette onto **Drop Zone 1**.

   A copy labeled **Table (dropped)** appears inside **Drop Zone 1**, and the status
   bar reads **Dropped Table into canvas**.

3. Drag the **Chart** widget onto **Drop Zone 2**.

   **Chart (dropped)** appears inside **Drop Zone 2**, and the status bar reads
   **Dropped Chart into canvas**.

The palette keeps its original widgets, so you can add the same widget more than
once.
