# Join a workspace

To join an existing workspace, you need an invitation code from the workspace
owner.

## Get your invitation code

1. Ask your workspace administrator to send you an invitation code. Codes start
   with `INV-`, for example `INV-2048`.

## Enter the code

2. Go to `http://localhost:8092/type-echo.html`.

3. In the **Type here:** field, enter your invitation code. This guide uses
   `INV-2048`.

   The code appears below the field so you can double-check it before you
   continue.

## Confirm your membership

4. Check your email inbox for a welcome message from the demo app team. It can
   take up to 10 minutes to arrive.

5. Click **Accept invitation** in the email to finish joining the workspace.
