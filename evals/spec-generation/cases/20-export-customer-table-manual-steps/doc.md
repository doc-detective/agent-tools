# Export the customer table for an audit

Auditors ask for a snapshot of the customer table each quarter. This procedure
shows how to check the table and file the snapshot.

## Before you begin

You need the **Analyst** role. If you don't have it, contact IT and ask for it to
be added to your account. Role changes take effect the next business day.

## Check the table

1. Sign in to your company SSO portal, then go to `http://localhost:8092`.

2. Scroll to the **Tables** section.

3. Confirm that the **Simple Data Table** lists all three customers:
   **John Doe**, **Jane Smith**, and **Bob Johnson**.

## File the snapshot

4. Press **Ctrl+P** (or **Cmd+P** on macOS) and save the page as a PDF.

5. Upload the PDF to the **Quarterly audits** folder on the compliance shared
   drive, and email the link to your audit lead.
