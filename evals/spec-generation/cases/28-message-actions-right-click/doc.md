# Use the message actions menu

Each message action button does one thing when you click it and another when you
right-click it. The results appear in the message panel below the buttons, oldest
first.

## Open the actions page

1. Go to `http://localhost:8092/click-shorthand.html`.

## Try both click types

2. Right-click **Reveal by selector**.

   The panel shows **Right-click landed**.

3. Now click **Reveal by selector** normally, with the left mouse button.

   **Selector click landed** appears under the first message.

## Run a pattern action

4. Click **Reveal via regex match**.

   **Regex click landed** appears at the bottom of the panel.
