# Open the account overview

The account overview collects panels from several services. Some services are
slower than others, so the panels arrive one at a time.

1. Go to `http://localhost:8092/annotate-late-element.html`.

   The status line **Ready immediately** shows as soon as the page opens.

2. Wait for the **Dashboard** panel. It can take up to ten seconds to appear, so
   give it time before you decide something's wrong.

3. Under the **Dashboard** panel, your three API keys are listed as **API key 1**,
   **API key 2**, and **API key 3**.

4. The **Billing** panel loads last, a second or two after the others.
