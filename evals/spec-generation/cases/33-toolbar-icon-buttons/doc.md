# Use the toolbar's icon buttons

To save space, the editor toolbar uses single-letter buttons. Each one posts a
confirmation to the message area under the toolbar.

1. Go to `http://localhost:8092/find-shorthand.html`.

2. Click **I** to insert an ID.

   The message area shows **Id click landed**.

3. Click **S** to apply a style.

   **Selector click landed** appears under the first message.

4. Click **Start late arrival** to queue a background job.

   The job takes a second or two. When it finishes, **Shorthand late arrival**
   appears in the message area.
