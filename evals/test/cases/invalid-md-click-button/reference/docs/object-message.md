# Add an object message

The **Reveal by object** button adds a sample message that notification templates
use as their placeholder.

## Add the message

<!-- test {"testId":"object-message"} -->
1. Go to `http://localhost:8092/click-shorthand.html`.
<!-- step {"goTo":"http://localhost:8092/click-shorthand.html"} -->
2. Click **Reveal by object** with the primary (left) mouse button.
<!-- step {"click":{"elementText":"Reveal by object","button":"left"}} -->

   The message **Object click landed** appears below the buttons.
<!-- step {"find":"Object click landed"} -->
<!-- test end -->

> **Tip:** Right-clicking the button opens the browser's menu instead, and no
> message appears.
