# Tour the demo app home page

The home page is the starting point for every task in the demo app. It groups the
app's controls into sections so you can find what you need quickly.

## Open the home page

1. In your browser, go to `http://localhost:8092`.

   You should see the page title **Common UI Elements** and a short introduction.

2. Look at the navigation menu near the top of the page. It links to each section,
   including **Text Inputs**, **Selection Elements**, and **Tables**.

## Review the sample data

3. Scroll down to the **Tables** section.

   You should see a table captioned **Simple Data Table** with three sample records.
   One of the rows belongs to **Jane Smith**.
