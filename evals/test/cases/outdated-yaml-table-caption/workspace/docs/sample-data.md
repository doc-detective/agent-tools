# Find the sample data table

The demo page ends with a small table of sample people. The reporting tutorials
use it as their input, so check that it's there before you start one.

1. Go to `http://localhost:8092/index.html`. The page heading reads
   **Common HTML Elements**.

2. In the navigation list, click **Tables**.

3. Find the table captioned **Sample Data Table**.

4. Check that **Jane Smith** is one of its rows.
