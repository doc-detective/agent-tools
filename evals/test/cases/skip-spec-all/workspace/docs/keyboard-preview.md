# Preview with the keyboard on __OTHER_PLATFORM_NAME__

These steps apply only to the __OTHER_PLATFORM_NAME__ desktop build.

1. Go to `http://localhost:8092/type-echo.html`.

2. Enter `Hello from __OTHER_PLATFORM_NAME__` in the **Type here:** field.

   The preview line reads **Hello from __OTHER_PLATFORM_NAME__**.

3. Go to `http://localhost:8092/click-shorthand.html` and click **Reveal by text**.

   The message **Text click landed** appears.
