# Lists and text inputs

The demo page shows the basic elements the editor tutorials build on.

## Check the ordered list

1. Go to `http://localhost:8092/index.html`.

2. In the **Lists** section, find the ordered list. Its first item reads
   **Step one**.

## On __OTHER_PLATFORM_NAME__: fill in the text input

These steps apply only to the __OTHER_PLATFORM_NAME__ desktop build, which
pre-fills the field from your profile.

1. Go to `http://localhost:8092/index.html`.

2. In the **Text Input:** field, enter `Hello from __OTHER_PLATFORM_NAME__`.
