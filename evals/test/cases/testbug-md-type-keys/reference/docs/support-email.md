# Preview your support address

Before you publish your profile, preview the support address that customers will
see. The preview shows the address exactly as you entered it, so it catches typos
before customers do.

## Preview the address

<!-- step {"goTo":"http://localhost:8092/multi-tab-child.html?page=profile"} -->
