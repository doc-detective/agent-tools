# Find the checkout buttons

The checkout flow starts from two buttons on the demo page.

1. Go to `http://localhost:8092/enhanced-elements.html`.

2. In the **Complex Combined Criteria** section, find the **Submit Order** button.
   It places the order with the items in your cart.

3. In the **Buttons with Various Criteria** section, find the large login button.
   It reads **Sign in**.
