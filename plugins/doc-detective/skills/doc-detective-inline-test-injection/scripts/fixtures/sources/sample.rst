Getting Started Guide
=====================

Introduction
------------

Welcome to our platform! This guide covers the essential first steps.

Accessing the Application
-------------------------

Go to `Example Application <https://example.com>`_ to begin.

.. tip:: Bookmark this URL for quick access later.

First Steps
-----------

When you arrive, verify that **Welcome** is displayed on screen.

Starting the Setup
~~~~~~~~~~~~~~~~~~

Click **Get Started** to proceed with configuration.

.. code-block:: bash

   curl https://api.example.com/status
